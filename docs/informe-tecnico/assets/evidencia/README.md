# Evidencia gráfica

Esta carpeta recibe capturas reales de Google Cloud Console para complementar el informe técnico. Los nombres esperados están definidos en la sección 10 de `../../informe/informe-tecnico-implementacion-gcp.md`.

No incluir secretos, tokens, correos personales, IDs de sesión ni contenido de mensajes sensibles. Cada captura debe mostrar el servicio, el proyecto correcto y el recurso que confirma.
