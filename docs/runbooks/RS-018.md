# RS-018 — API privada de Insights

Los scripts 63–67 despliegan una API privada de Cloud Run para consultar las
tablas Gold. Sus nombres dependen de `PREFIX`, `PROJECT_ID` y `REGION` de
`config.env`:

- Servicio: `${PREFIX}-insights-api`.
- Runtime: `${PREFIX}-api@${PROJECT_ID}.iam.gserviceaccount.com`.
- Acceso BigQuery: limitado a las tablas Gold definidas en
  `config/contracts/retailsmart_api.json`.

El script 66 valida el recurso, la revisión, IAM y las cuatro rutas de negocio.
Una ruta `/healthz` no es requisito de aceptación.

## Verificación manual

```bash
source scripts/common.sh
SERVICE="${PREFIX}-insights-api"
URL="$(gcloud run services describe "$SERVICE" --project="$PROJECT_ID" --region="$REGION" --format='value(status.url)')"
TOKEN="$(gcloud auth print-identity-token)"

for path in \
  '/api/v1/insights?limit=5' \
  '/api/v1/kpis?limit=5' \
  '/api/v1/inventory-plans?limit=5' \
  '/api/v1/maintenance-risks?limit=5'; do
  curl -i -H "Authorization: Bearer $TOKEN" "$URL$path"
done
```

Cada ruta debe devolver HTTP 200 con datos. La evidencia se guarda en
`state/<DEMO_RUN_ID>/EVIDENCIA_API_RETAILSMART.md`.
